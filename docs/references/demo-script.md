# Demo Video Script

This is a short, tight demo plan intended for a public post.

## Target Length

- 45 to 75 seconds

## Recording Goal

Show that the bridge is real, local, app-aware, and already useful.

## Shot List

1. Opening shot: controller in hand + macOS desktop visible
   - Voiceover:
     - “I built a local bridge that turns a Stadia controller into a real macOS control surface.”

2. Ghostty tab/split control
   - Show:
     - switching tabs
     - moving between splits
     - resizing a split
   - Voiceover:
     - “Ghostty is the main target right now, so terminal navigation is mapped directly to controller actions.”

3. Ghostty scrolling
   - Show:
     - focused terminal scroll with the stick
   - Voiceover:
     - “Scrolling follows the focused Ghostty surface instead of the mouse cursor.”

4. Codex profile
   - Show:
     - switch chat threads
     - focus the chat box
     - type a draft
     - clear it with triangle
   - Voiceover:
     - “Codex gets its own profile too, including thread navigation and draft clearing.”

5. Arc profile
   - Show:
     - stick-controlled pointer movement
     - scroll
     - click
     - refresh or copy URL
   - Voiceover:
     - “Arc gets browser-style controls with pointer, scroll, click, and shortcuts.”

6. Explicit-profile behavior
   - Show:
     - switch to an unmapped app
     - only always-on controls still work
   - Voiceover:
     - “It does not guess. If an app is not explicitly profiled, only always-on controls fire.”

7. Closing shot: config file or repo README
   - Voiceover:
     - “The whole thing is local, config-driven, and built with native macOS frameworks.”

## Recording Guidance

- Start with all target apps already open.
- Use medium-sized windows so Ghostty and Codex actions are visually obvious.
- Keep the controller in frame for at least the first 3 to 5 seconds.
- Prefer one clean pass over lots of edits.
- If you add captions, keep them blunt:
  - `Ghostty profile`
  - `Codex profile`
  - `Arc profile`
  - `Explicit app mapping`

## Optional On-Screen Caption Sequence

1. `Stadia controller -> macOS apps`
2. `Ghostty tabs, splits, scroll`
3. `Codex threads + clear draft`
4. `Arc pointer + click + scroll`
5. `Local. Explicit. Config-driven.`
